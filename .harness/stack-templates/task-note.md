# 模板：任务记录（一轮改动的落痕）

复制到 `.harness/tasks/<id>-<动宾短语>.md`。存在的理由只有一个：**下一个人能复现这一轮**，
包括它失败的样子。

```text
id：<board.json 里的同号条目，没有就先建一条>
改了什么：<文件与动作，逐条，不写「优化了些东西」>
为什么这么改：<约束或事故，不是「更好」>
跑了什么：make check / make check-all / make selftest（附退出码）
三个数：改动文件 <n> 个、校验 <n> 轮、提交 <n> 个
不显然之处：<这一轮里只有做过才知道的那一句>
```

- 三个数必须是现算的（`git diff --stat`、跑了几次就是几次）。**估算值不是事实**：
  写「大概花了两个小时」对下一个人没有任何帮助。
- 「不显然之处」写不出来，就说明这一轮没什么可记——那就只更新看板，别造一篇语料。
- 完成态不在这里表达，在看板 `board.json` 里：`status: done` + `evidence: commit:<sha>`
  或 `path:<存在的文件>`（`STATE005`/`STATE006` 会核验它）。
