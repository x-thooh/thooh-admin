# docs/ — swagger 生成物

`docs.go` / `swagger.json` / `swagger.yaml` 都是 `swag init` 的产物，第一行就写着
`Code generated by swaggo/swag. DO NOT EDIT`。**改文档 = 改注解再生成**，不手改：

- 全局元信息（title/version/description/host/basePath）在 `main.go` 顶部的
  `// @title` 一类注解里。
- 单条接口在 `modules/**/api.go` 的 `// @Router` 注解里。

断言按三方对账判：`main.go` 注解 ↔ `swagger.json` ↔ `swagger.yaml`，谁少了一截就报，
以 `main.go` 为准。`scope=stale`

现状：全库 0 条 `@Router`，所以 `paths` 为空、时效判定登记为「判不了」而不是通过。
补注解是单独一轮（每个模块的 handler 都要写），别在功能提交里顺手加。
